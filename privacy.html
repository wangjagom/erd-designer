ERD 설계 도구 · 시행일 2026년 11월 10일

1. 수집하는 정보

간편 로그인(Google · GitHub)을 사용하면 해당 서비스가 제공하는 아래 정보만 받아요.

  • 이메일 주소
  • 이름(닉네임)과 프로필 사진 주소
  • 로그인 제공자가 부여한 사용자 식별자

로그인하지 않으면 아무 정보도 서버로 보내지 않아요. 작업 중인 ERD는 브라우저(localStorage)에만 저장돼요.

2. 이용 목적

  • 로그인 상태 유지와 본인 확인
  • 사용자가 직접 저장한 ERD를 보관하고 다시 불러오기
  • 사용자가 켠 경우에 한해 읽기 전용 공유 링크 제공

광고, 마케팅, 제3자 판매에는 사용하지 않아요.

3. 보관과 처리 위탁

로그인 정보와 저장한 ERD는 Supabase(서울 리전)에 보관돼요. 저장한 ERD는 본인만 읽고 쓸 수 있고, 공유를 켠 ERD만 링크를 아는 사람이 읽기 전용으로 볼 수 있어요.

4. 보관 기간과 삭제

ERD는 사용자가 삭제할 때까지 보관돼요. 클라우드 창의 내 ERD에서 언제든 삭제할 수 있어요. 계정과 모든 데이터 삭제를 원하면 아래 연락처로 요청해 주세요. 계정을 지우면 저장한 ERD도 함께 삭제돼요.
